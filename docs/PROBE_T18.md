## 5. 125 MHz 判断与工作量

结论：当前结构配合已试设置，布线后125 MHz到不了；需处理服务控制和收发 RAM 控制的多处长连线，不能称为接近达标，也没有证据保证仅调工具参数可以收敛。
条件估计：其余路径完全不变，仅消除615A目的端违例，残余上限约56.686 MHz；再消除SNMP目的端约66.778 MHz；再清RTC/配置约76.005 MHz。由当前残余最差裕量换算，跨模块路径保留，均非修改后实测频率。
建议工作范围：615A 条件解码/状态选择、SNMP OID比较/状态选择优先拆成约3段（新增2处寄存边界）；RTC/配置广播、收发 RAM 地址/使能考虑局部复制并增加约1级；MAC和服务仲裁还需少量收尾。具体级数须按新布局复核，不是只加几个寄存器就能保证通过。
工作量粗估5～10人日，含握手/状态对齐、RTL与网表回归及多轮布局布线；这是工程估算，本卡没有改RTL验证，125 MHz能否留出稳定裕量仍未知。
每新增一级在125 MHz下增加8 ns固定延迟；若引入等待或改变仲裁，相邻帧间隔、抖动和RTC误差也会改变。须保持每周期一字节吞吐，并同步调整地址、数据、有效信号与时间戳，再重测已有指标。
