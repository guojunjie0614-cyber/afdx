# Triage Labels

本地任务通过顶部的 `Status:` 行记录分诊状态。

| 技能角色 | 本项目状态 | 含义 |
|---|---|---|
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可交给代理实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不予处理 |

技能提及分诊角色时，使用表中的对应状态。
Wayfinding 的认领和完成状态另见 `issue-tracker.md`。
