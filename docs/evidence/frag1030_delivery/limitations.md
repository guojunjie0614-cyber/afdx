# 限制与验证边界说明

- **81 VL 超规格压力测试边界**：81 VL 背靠背 BAG 等待场景（case 16）中有 10/162 组抖动 `>= 100 µs`（最大 `107.7 µs`，VL `0x0126` 双向）；81 VL 长短消息混合会触发 RX 溢出。当前工程满负载并发规格统一标定为 **63 TX / 63 RX VL**（固定激励混合二分 70 通过、71 溢出，取 63 VL 留约 10% 余量；77/81 VL 数据保留为超规格压力测试参考）。
- **分片与多 VL 并发长消息边界**：已验证 63 VL 混合工况下单条 VL 发送 8192 B 长消息；多条 VL 并发连续发送 8192 B 仅 `N = 2`（20 ms 窗口）通过，`N = 3/4` 受 256 页发送缓冲预算限制，不作多 VL 并发长消息规格保证。
- **网表仿真覆盖边界**：8192 B 长消息分片与双冗余故障恢复主要在全量 RTL 上完成全窗口验证；分片功能官方 VQM 门级对照验证了截断至第 199,578 拍的稳定前缀（含 1472 B 两帧重组与双通道 TX/RX 逐字节比对）。
- **eLinx 界面行为仿真**：已于界面 Run Behavioral Simulation 人工实测通过：`[RESULT] tb_elinx PASS checks=9238 errors=0`，耗时 `0:02:18`；原始截图见 [elinx_gui_behav_pass.png](../vl63_full_load/elinx_gui_behav_pass.png)，警告明细见 [63 VL 验证汇总](../vl63_full_load/summary.md#elinx-界面仿真验证)。
- **VQM 综合文本排列与布线可复现性**：eLinx 不同次综合导出的 VQM 文件内部同构节点枚举顺序可能存在文本排列差异，但逻辑单元与连接完全同构；导入锁定位置约束后，时序与落位结果保持一致（见 [布线与 STA 复现](../route_sta/summary.md)）。
