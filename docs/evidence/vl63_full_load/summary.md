# 63 VL 满负载声明与验证

当前满负载并发规格标定为 **63 TX / 63 RX VL**，每 VL `BAG = 1 ms`、`Lmax = 1471 B`，A/B 双冗余双向同时运行；表项配置规模仍为 TX 128 / RX 4096。计划单向应用载荷 `741.384 Mbit/s`（含额外 VLID 输入口口径为 `742.392 Mbit/s`），千兆线路占用率 `63 × 1538 / 125000 = 77.5152%`（约 `77.5%`）。

### B1 公式不成立组说明

B1 场景的 HDL、逐字节完整性与双统计均全数通过。由于 B1 采用固定输入顺序，有 `122/126` 组不满足 `最大端到端 − 首帧端到端 > BAG` 的差值测量前提（原始清单见 [formula_invalid_groups.tsv](formula_invalid_groups.tsv)）。以方向 0 的 VL `0x0100`（1471 B）为例：首帧端到端 `6073` 拍（`48.584 µs`），全程最大 `129600` 拍（`1036.800 µs`），差值 `988.216 µs <= 1000 µs`（减 BAG 后为 `-11.784 µs`），因此记为 `NA`。这并不说明未等 BAG——线上两方向各 `3,150` 对消息的 BAG 等待校验均 0 失败，有效 4 组最大抖动为 `0.984 µs`（`0x0115`），完整的背靠背抖动判据由轮换输入相位的 B2 场景承担。

## 混合负载与超规格压力参考

- **63 VL 混合场景**：引用 [负载与压力边界记录](../frag_load/summary.md) 中 `VL_COUNT = 63, MIXED = 1, DURATION = 12500000`（`100 ms`）结果，HDL/逐字节完整性通过、双统计一致、页池上界 `<= 256`。
- **81 VL 超规格压力参考**：在早期 81 VL 满载实验中，周期注入最大抖动 `3.368 µs`；BAG 对齐撞车 case 16 有 `10/162` 组 `>= 100 µs`（最大 `107.7 µs`，VL `0x0126`）；81 VL 长短混合场景出现 RX 溢出。该组结果保留用于说明超出 63 VL 规格后的系统极限，不作为满负载承诺。
