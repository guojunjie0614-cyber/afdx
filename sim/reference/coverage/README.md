# RTL 覆盖率结果

ModelSim SE-64 2020.4 对完整 38 项回归统计 `sbceft`，测试平台未插桩。`modules.csv` 每行一个 RTL 模块；`vcover_report.txt` 顺序拼接 21 份按设计单元原始报告，仅统一 LF 换行，统计内容未改写；`merged.ucdb` 为合并结果。两轮结果、耗时和总体数字见 `totals.json`。
总体按各模块已覆盖统计项（coverage bin）数合计计算，百分比保留两位并按工具习惯截断；状态机（Finite State Machine, FSM）合计包含状态和转换，也分别列出两类数值。`N/A` 表示没有该类统计项。
条件未达 80%：例如 `rtl/afdx_615a.v:697–698` 的忙状态写配置、零值端口/超时条件没有命中否定项；RAM 的编译期函数与禁止碰撞检查也保留在统计中。
FSM 合计未达 80%：状态全部命中，转换仍有缺项；例如报告列出 `B_MESSAGE_TAG → B_VALUE_TAG`（`rtl/afdx_snmp.v:1131`）未命中，该赋值位于外层 `COPY_OID`，实际从 `B_OID` 到 `B_VALUE_TAG`，工具对内层 `part` 状态机列出了额外跨状态弧。
翻转未达 80%：例如 `afdx_cfg` 的 `count_a_fcs[2:31]`、`count_tx_a[14:31]` 在报告中两个方向均为零，现有测试计数没有达到这些高位；未覆盖项未排除。

排版与常量命名后重跑：两轮完整回归均为 38/38，项数与参考输出一致；21 个模块的各项覆盖率百分比和统计项数与整理前完全一致。
